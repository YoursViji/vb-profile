# Vijay Baskaran Arjun Dev — portfolio

Public resume and portfolio site for **Vijay Baskaran Arjun Dev**, Head of Software Technologies at Retailetics. Dark, in-store retail-tech presentation: scan-pay-go carts, kiosks, cart security, and indoor navigation, plus an independent TAN Intelligence venture.

## Run locally

Requires Node.js 20+.

```bash
npm install
npm run dev
```

The app listens on **http://127.0.0.1:43217** (not 3000). Open that URL.

Production-style check:

```bash
npm run build
npm start
```
