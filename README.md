## Run locally

Requires Node.js 20+.

```bash
git clone https://github.com/YoursViji/vb-profile.git
cd vb-profile
npm install
npm run dev
```

The app listens on **http://127.0.0.1:43217** (not 3000). That address is local-only.

```bash
npm run build
```

The production site is the public GitHub Pages URL above.
