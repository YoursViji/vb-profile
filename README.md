## Run locally

Requires Node.js 20+.

```bash
git clone https://github.com/YoursViji/vb-profile.git
cd vb-profile
npm install
NEXT_PUBLIC_BASE_PATH=/vb-profile npm run dev
```

The app listens on **http://127.0.0.1:43217**.

```bash
NEXT_PUBLIC_BASE_PATH=/vb-profile npm run build
```
